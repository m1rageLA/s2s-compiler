## Что лежит в `config/` и зачем

- `tsconfig.base.json` — базовые опции TypeScript: таргет, модульность, строгий режим. Держите здесь то, что должно применяться везде.
- `tsconfig.heavy.json` — надстройка над базой для файлов с трансформером `heavy.cjs` (путь `../transformer/heavy.cjs` указан относительно этой папки). Подключает плагин и задаёт include/exclude.
- Корневой `tsconfig.json` просто указывает на `config/tsconfig.heavy.json`, чтобы старые команды продолжили работать.

### Как «играть кубиками»
- Нужно добавить ещё один профиль? Скопируйте `tsconfig.heavy.json`, поправьте имя файла и нужные поля, потом укажите `extends` на базу.
- Хотите отключить плагин — работайте напрямую с `tsconfig.base.json` или сделайте новый профиль без секции `plugins`.
- Хотите сузить область компиляции для эксперимента — в своём профиле поменяйте `include`/`exclude`, не трогая базу.
